# Briefs

Design briefs for Claude Design, one `UPPERCASE.md` file per screen or flow.
A plan that adds a screen, or reshapes one, waits for a design before it is
approved: a layout is cheap to argue over on a canvas and expensive in a diff.
Each brief opens with this repository's link (https://github.com/masshirodev/yomu, public) and the
files the designer should read, so the design starts from the real code, and
ends by asking the designer to append ` [finished]` to the design's title and
close it with `Status: finished`, since nothing else says a design is done.
`hajime check` holds these three things.

A brief whose handoff has been implemented moves to `done/`.
